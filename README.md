# CVQuick

CVQuick helps people create a professional CV by answering simple questions.

## What it does

- Asks questions about skills, experience, education, and languages.
- Supports formal work, informal work, volunteering, and projects.
- Creates a clear CV draft.
- Lets users print or save the CV as a PDF.
- Works in a web browser.

## Important

Users must check all information before using the CV. The app must not invent qualifications, employers, dates, skills, or achievements.

## Project status

This is an early prototype. Future improvements may include voice answers, more templates, cover letters, job matching, and additional languages.
